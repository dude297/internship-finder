## Findings and open items

- **Security review (final):** no BLOCKER or HIGH. MEDIUM: the login throttle shares the proxy bucket, so an attacker can lock the owner out for 15 minutes (availability only). MEDIUM: Revert to source is irreversible (the UI asks for confirmation). LOW: the PDF child process inherits the environment; the backup scripts pass the database URL on the command line; CI checkout should set `persist-credentials: false`.
- **Feed-free readiness**, tested on disposable databases: fresh install without the feed, feed retired, feed failed, and feed disabled all PASS. Technically GO, conditional on accepting the loss of about 1,016 feed-only postings (about 800 on Workday/Oracle, which have no adapter). The production feed was not retired.
- **Disposable-database test:** the SpaceX catalog entry fails like Anduril (response too large, 20 MiB cap).
- **Known fit v2 gaps:** multi-city locations and "United States of America" miss the Bay Area region; Foster City, San Carlos and Livermore are not in the region table; no RTL/FPGA/VLSI/PyTorch aliases; empty availability dates mean the schedule never contributes.
- **Owner actions pending:** backup activation (install `age`, `age-keygen` to private storage, `gh variable set BACKUP_AGE_RECIPIENT` with the public key, dispatch once, restore drill); Render build command to `pip install -r requirements.lock && pip install --no-deps .`; review the 558 pending suggestions.
