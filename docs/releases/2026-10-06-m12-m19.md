### Incident: scheduled sync halted 18:55–22:21

Merging #55 and #57 put two migrations on `main` before Neon was migrated; the scheduled sync runs `main`'s code and refused ("the database schema isn't at this code's migration head"), writing nothing. The owner ran `alembic upgrade head` (`a3c7e9b1d5f2` → `c8d2f4a6b0e3` → `c9e2b7a4d1f8`, both additive; the deployed `cf1ad43` backend tolerated them). Dispatched run [37540073778](https://github.com/dude297/internship-finder/actions/runs/37540073778): 47 sources, 0 failed, 370.0 s (18 h of backlog; feed created 45, closed 7). Lesson recorded: don't merge a migration PR without migrating Neon in the same window.
